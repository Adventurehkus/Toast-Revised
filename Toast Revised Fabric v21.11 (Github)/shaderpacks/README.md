# 📦 Manifest & Distribution Rights: Shaderpacks

Welcome to the internal asset directory for Toast Revised.

## ⚠️ Why is this folder empty?

To fully support original artists and honor their specific distribution guidelines, no shaderpack .zip files are hosted directly within this repository. Hosting raw asset packs violates creator permissions and bypasses traffic to their official project spaces.

When players install Toast Revised via an official launcher, these asset configurations are securely bundled or linked using approved distribution channels to ensure creators receive full credit and support.

The following hand-picked cinematic and performance-optimized shader pipeline is configured for this build profile:
