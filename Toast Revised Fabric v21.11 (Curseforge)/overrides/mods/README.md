# 📦 Manifest & Distribution Rights: Mods

Welcome to the internal mod directory for **Toast Revised**. 

### ⚠️ Why is this folder empty?
To strictly respect the distribution rights, licensing, and monetization mechanics of the incredible developers in the Minecraft modding ecosystem, **no third-party mod `.jar` files are hosted directly within this repository.** 

When Toast Revised is exported and distributed through official platforms like Modrinth and CurseForge, these mods are automatically fetched and downloaded securely from their original sources via the project's manifest indexes.

### 📋 Target Engine Manifest
The following core modifications are mapped to this specific build profile and will compile into this directory upon installation:

*   **Axiom** (`Axiom-5.3.0-for-MC1.21.11.jar`)
*   **Better Selection** (`better-selection-1.8.jar`)
*   **Symbol Chat** (`symbol-chat-1.21.11-1.3.13.jar`)
